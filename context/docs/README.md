# context/docs

Dokumentacja bibliotek pobrana z Context7 (`npx ctx7@latest docs`) podczas researchu zmian. Jeden plik na bibliotekę (`<biblioteka>.md`); nagłówek pliku zawiera library ID, zapytania, datę pobrania i link do źródła, potem treść. Podsumowanie wyników researchu (odpowiedzi, decyzje, źródła) trafia do `## Notes` w `change.md` danej zmiany.
